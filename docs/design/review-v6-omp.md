# v6 设计稿评审报告（omp）

## 总体评价

设计稿整体质量高，功能覆盖完整（5/5 页面），视觉语言统一：玻璃拟态 + 渐变 accent + Inter 排版体系达到接近 Stripe/Raycast 的成品水准。**评分 7.8/10**。主要扣分项：Settings 页面 4/5 分区处于"即将支持"占位状态（无交互 mockup），Dashboard HTML title 残留 v5 命名，以及卡券圆角设计系统与 CSS 实现存在 4px 偏差。

## 优点

- **配色体系严谨**：9 色 token 跨 5 页面完全一致，无游离色。accent 渐变 `#6366f1→#8b5cf6` 在各页面 badge/button/progress bar 复用正确。
- **排版层级清晰**：H1(20)/Body(14)/Secondary(13)/Weak(11) 分级明确，Inter 字体应用统一。
- **玻璃拟态执行到位**：悬浮窗 `backdrop-filter: blur(24px)` + `rgba(255,255,255,0.8)` 符合 spec，阴影多层的柔和感很好（`shadow-float: 0 12px 40px…`）。
- **跨页面组件复用**：card/badge/table/token-grid 在 Dashboard/History/Models/Settings 间保持结构一致。
- **功能覆盖完整**：5 个页面的核心功能（3 账号配额、使用记录表格、模型分布、设置管理、悬浮窗）均已呈现。

## 竞品对比

| 维度 | Usage Float v6 | Linear | Vercel | Stripe | Raycast |
|---|---|---|---|---|---|
| **配色** | 浅灰 bg + 玻璃白卡 + 紫渐变 | 深色/浅色 + 紫 accent | 黑白极简 + accent | 白 + 渐变深蓝紫 | 玻璃底栏 + 渐变 accent |
| **玻璃拟态** | ✅ 卡片 `blur(20px)`，悬浮窗 `blur(24px)` | ❌ 无玻璃拟态 | ❌ 纯色 | ⚠️ 部分渐变叠加 | ✅ 菜单栏模糊效果 |
| **排版** | Inter 14/13/11/10，层级清晰 | Inter 体系成熟 | Inter 极致间距 | Inter 商务排版 | Inter 紧凑信息密度 |
| **信息密度** | 较高（3×圆环 + token + 模型） | 中（条目式） | 低（留白多） | 中-高（dashboard 密集） | 高（悬浮窗/菜单） |
| **暗色模式** | ❌ "即将支持" | ✅ 原生支持 | ✅ 原生支持 | ✅ 原生支持 | ✅ 自适应 |
| **圆角语言** | 大圆角 12-20px | 小圆角 6-8px | 中圆角 8-12px | 中圆角 8-12px | 大圆角 12-20px |
| **动画/过渡** | card hover translateY(-1px) ✅ | 流畅微动效 | 克制 | 平滑过渡 | 细腻弹性动画 |
| **响应式** | 固定 600px panel | ✅ 自适应 | ✅ 自适应 | ✅ 自适应 | 固定宽高 |

**优势**：玻璃拟态执行深度领先 Linear/Vercel，圆角语言接近 Raycast，配色方案与 Linear 的紫 accent 一脉相承。

**差距**：暗色模式缺失（竞品标配），无微动画（Linear 的列表进出/Vercel 的 page transition），面板固定 600px 不响应窗口缩放（桌面端应至少 600-800px 自适应），Settings 页面完成度远低于竞品成熟度。

**需小迭代**（Dev Ready + 补充状态稿后即可进入实现）。
