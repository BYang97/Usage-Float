# v0.4 Usage History(/_server RPC)

## 目标
History 页加 usage 明细列表(model/provider/tokens/cost),数据从 opencode.ai /_server RPC(参考 opencode-go-dashboard fetchGoUsageHistory)。

## 调研结果
/_server RPC POST https://opencode.ai/_server:
- payload: `{"t":{"t":9,"i":0,"l":2,"a":[{"t":1,"s":wsId},{"t":0,"s":cursor}],"o":0},"f":31,"m":[]}`
- headers: Content-Type json, Cookie auth={cookie}, Origin/Referer opencode.ai, x-server-instance server-fn:2, x-server-id bfd684bfc2e4eed05cd0b518f5e4eafd3f3376e3938abb9e536e7c03df831e5c
- 响应: React flight 数据,含 usg_xxx 记录(id/workspaceID/timeCreated/timeUpdated/model/provider/inputTokens/outputTokens/reasoningTokens/cacheReadTokens/cost/keyID/sessionID/plan)

## 改动
### src-tauri/src/collector/api.rs
加 `fetch_usage_history(&self, cursor: i64) -> Result<Vec<UsageHistoryItem>, CollectorError>`:
- POST /_server(payload + headers 同上)
- 解析 usg_xxx 记录(参考 /tmp/opencode-go-dashboard/src/worker/quota.ts parseHistoryBody: 按 id:"usg_" 锚点切片,正则提字段)
- UsageHistoryItem { id, time_created, model, provider, input_tokens, output_tokens, reasoning_tokens, cache_read_tokens, cost, key_id, session_id }

### src-tauri/src/collector/model.rs
加 UsageHistoryItem struct(serde camelCase? 前端用 snake_case 匹配 Account,所以不用 camelCase)。

### src-tauri/src/lib.rs
加 Tauri 命令 `get_usage_history(account_id: String, cursor: i64) -> Result<Vec<UsageHistoryItem>, String>`:
- 按 account_id 取 cookie+ws,调 fetch_usage_history
- 注册到 invoke_handler

### web/src/pages/History.tsx
加 usage 明细列表(每条:model/provider/tokens/cost),调 invoke('get_usage_history', { accountId, cursor })。
accountId 从 list_accounts 取第一个(或账号选择器,简化用第一个)。

## 注意
- /_server RPC 要 x-server-id(参考项目用固定值,可能过期;若 404/401 调研真实值)
- cursor 分页(0 开始,返回下一页 cursor)
- usg_ 记录解析按 id 锚点切片(参考 parseHistoryBody)
