# v0.3 项目级日志系统

## 目标
加文件日志(Rust tauri_plugin_log 文件 target)+ 前端 logger 封装,方便调试 + 端到端测试定位问题。

## 改动
### src-tauri/src/lib.rs (tauri_plugin_log 配置)
当前:`tauri_plugin_log::Builder::default().level(log::LevelFilter::Info).build()`
改为加文件 target + Debug level:
```rust
tauri_plugin_log::Builder::default()
    .level(log::LevelFilter::Debug)
    .targets([
        tauri_plugin_log::Target::new(tauri_plugin_log::TargetKind::Stdout),
        tauri_plugin_log::Target::new(tauri_plugin_log::TargetKind::LogDir { file_name: None }),
        tauri_plugin_log::Target::new(tauri_plugin_log::TargetKind::Webview),
    ])
    .build()
```
关键路径加 log:
- fetch_api_quota: `log::info!("[fetch_api_quota] cookie len={}, ws={}", ...)` + `log::error!` 失败
- list_accounts/create_account/refresh_one: `log::info!` 调用

### web/src/services/logger.ts (新建)
前端 logger 封装:
```ts
export const logger = {
  info: (msg: string, ...args: any[]) => console.log(`[info] ${msg}`, ...args),
  warn: (msg: string, ...args: any[]) => console.warn(`[warn] ${msg}`, ...args),
  error: (msg: string, ...args: any[]) => console.error(`[error] ${msg}`, ...args),
};
```
关键路径用 logger(替换 console):
- usage-service, TauriProvider, AccountDialog, AccountTable

## 验证
- `cargo build` 编译通过
- `cd web && bunx tsc --noEmit` 零错误
- 运行 app 后 app_data_dir/logs 有日志文件

## 注意
- tauri_plugin_log TargetKind::LogDir 输出到 app_data_dir/logs(确认 API 签名,可能要 file_name: None)
- 前端 logger 简单封装 console(不转发 Rust,避免循环依赖)
