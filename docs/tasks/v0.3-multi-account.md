# v0.3 多账号管理 - Plan 契约

## 目标
单账号设置页 -> 多账号管理(参考 opencode-go-dashboard AccountDialog + AccountTable)。

## 数据模型
```rust
pub struct Account {
  pub id: String,          // "acc_" + uuid
  pub name: String,        // 显示名称
  pub workspace_id: String,// wrk_xxx
  pub auth_cookie: String, // Fe26.2**
  pub notes: String,       // 备注
  pub created_at: i64,     // 毫秒时间戳
  pub updated_at: i64,
}
// 前端 AccountWithUsage { account: Account, usage: UsageResult | null }
```

## db schema (database.rs)
accounts 表:
```sql
CREATE TABLE IF NOT EXISTS accounts (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  workspace_id TEXT NOT NULL,
  auth_cookie TEXT NOT NULL,
  notes TEXT NOT NULL DEFAULT '',
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
```
CRUD(都加解密 auth_cookie,复用现有 ring AEAD encrypt/decrypt):
- `list_accounts(conn) -> Vec<Account>`
- `get_account(conn, id) -> Option<Account>`
- `create_account(conn, form) -> Account`
- `update_account(conn, id, form) -> Option<Account>`(auth_cookie 留空则保持不变)
- `delete_account(conn, id) -> bool`
迁移:init_schema 里,若 accounts 表空且 settings 有 opencode_auth_cookie,则插入一条默认账号(name="默认")。

## Tauri 命令 (lib.rs,替换 get/set_opencode_cookie + workspace_id)
- `list_accounts() -> Vec<Account>`
- `create_account(form: AccountForm) -> Account`
- `update_account(id: String, form: AccountForm) -> Account`
- `delete_account(id: String) -> ()`
- `refresh_one(account_id: String) -> UsageResult`(按 account 取 cookie+ws 调 fetch_quota)
- `refresh_all() -> Vec<AccountWithUsage>`
保留 `fetch_api_quota` 内部逻辑(按 cookie+ws fetch),命令层按 account_id 取。

## UI 组件 (web/src)
- `AccountDialog.tsx`: name+workspaceId+authCookie+notes 表单(参考 opencode-go-dashboard AccountDialog,SensitiveInput 用 type=text+WebkitTextSecurity)
- `AccountTable.tsx`: 账号列表卡片(名称+workspaceId+配额三窗口+刷新/编辑/删除按钮)
- `Settings.tsx` 改造: 用 AccountTable + AccountDialog 替代单账号表单(删 cookie/workspaceId state,改 accounts list)

## DAG 拆分(omp 任务)
1. **db-migration**(依赖 plan): database.rs accounts 表 + CRUD + 迁移
2. **api-multi**(依赖 db): lib.rs fetch_quota 按 account_id(或保留 cookie+ws,命令层取)
3. **tauri-cmds**(依赖 db,api): list/create/update/delete + refresh_one/all 命令
4. **account-dialog**(依赖 plan): AccountDialog.tsx
5. **account-table**(依赖 dialog,cmds): AccountTable.tsx
6. **settings-refactor**(依赖 table): Settings.tsx 改账号管理
