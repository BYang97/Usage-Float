# v0.3 History/Models 页实现

## 目标
侧边栏"使用记录"(history)和"模型统计"(models)点击无反应(当前 App.tsx 渲染 Dashboard 占位)。实现专门页。

## 改动
### web/src/pages/History.tsx (新建)
使用记录页,布局同 Dashboard(Sidebar + Header):
- token 今日/7天/30天 卡片(从 getUsageData() 的 tokens.tokenToday/token7d/token30d)
- tokenHistory 折线图(tokens.tokenHistory: TokenRecord[]{date,tokens})
- 数据来自 usage-service getUsageData(订阅 + autoRefresh)

### web/src/pages/Models.tsx (新建)
模型统计页,布局同 Dashboard:
- models 占比(models: ModelUsageData[]{name,percentage,color})条形图/列表
- 数据来自 usage-service getUsageData

### web/src/App.tsx 路由
- `page === 'history'` 渲染 `<History onNavigate={...} />`(替代 Dashboard 占位)
- `page === 'models'` 渲染 `<Models onNavigate={...} />`
- History/Models 接受 onNavigate prop(同 Dashboard)

## 参考
- Dashboard.tsx 布局(Sidebar + Header + 内容)
- types/index.ts: TokenInfo, ModelUsageData, UsageData
- usage-service: getUsageData, subscribe, startAutoRefresh
